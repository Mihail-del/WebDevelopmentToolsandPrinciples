# Макеты сувенирной лавки

Сгенерированы встроенным image_gen 17 ноября 2026 года. Это концептуальные desktop-макеты, не готовый сайт. Мобильные макеты пока не создавались.

1. 01-home.png — главная, слайдер, категории, товары, блок «О магазине».
2. 02-catalog.png — каталог, подменю, поиск, фильтры, сортировка и пагинация.
3. 03-product.png — товар, галерея, количество, корзина, избранное.
4. 04-favorites.png — избранное.
5. 05-cart.png — корзина и сумма заказа.
6. 06-checkout.png — контактные данные и доставка.
7. 07-contacts.png — демонстрационные контакты, карта, FAQ.
8. 08-order-success.png — успешное оформление демонстрационного заказа.

Стиль: светлый кремовый фон, терракотовые акценты, заголовки с засечками, фотографии сувениров из городов Украины. Главная служит визуальным образцом для остальных страниц.

Промпты сохранены в prompts.json. Окончательные макеты находятся непосредственно в этой папке; ранние варианты не используются.

При реализации: унифицировать названия и цены товаров между страницами; в подтверждении заказа должны быть 2 набора открыток по 120 грн, как в корзине, а не один за 240 грн. Состояние выбранных фильтров должно соответствовать результатам. Цены и текст на картинках иллюстративные. Галерею выполнить 300×300 px по заданию независимо от пропорций изображений на макете. Разделители поставить между всеми пунктами меню; на мобильном адаптировать меню и сетку. Карта на изображении схематическая — на сайте использовать реальную карту. Предусмотреть пустые состояния, ошибки формы, отсутствие результатов и 404 в коде.
